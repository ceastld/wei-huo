# 尾火

你跑过的路会在两秒后爆炸。用自己的尾巴当炸弹，别被过去的自己炸到。

玩：https://ceastld.github.io/wei-huo/

## 操作
- 键盘：WASD / 方向键移动，空格冲刺，R 重开本房
- 触屏：左下摇杆移动，右下「冲」冲刺
- 鼠标：按住画布朝指针方向走

## 八房
空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市 → 循径 → 双刃。
吃到心核进下一房；双刃心核通关。R 只重开当前房。

站立不铺焰辙。辙 2.0 秒后爆。自己的爆会伤自己。
心×3。爆、碰敌人、出界各掉 1 心。水洼熄辙。箱挡路，爆开才让。
**循辙**顺着你的活焰辙冲过来；没辙时只慢走。两下任意爆放倒。水洼切断它们的公路。
