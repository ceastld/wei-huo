# 尾火

你跑过的路会在两秒后爆炸。用自己的尾巴当炸弹，别被过去的自己炸到。

玩：https://ceastld.github.io/wei-huo/

## 操作
- 键盘：WASD / 方向键移动，空格冲刺，R 重开本房，N 下一房（作弊）
- 触屏：左下摇杆移动，右下「冲」冲刺
- 鼠标：按住画布朝指针方向走

## v1 六房
空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市。吃到心核进下一房，夜市通关。
移动才留焰辙（约 18px 一颗），站立不铺。辙正好 2.0 秒后爆。冲刺辙更烫。
箱挡路，爆开才让。水洼灭辙。烬卫慢追，三下爆死。自己的爆也会伤自己。
心×3。被爆 / 碰烬卫 / 出界各掉 1 心。
