# 尾火

你跑过的路会在两秒后爆炸。用自己的尾巴当炸弹，别被过去的自己炸到。

玩：https://ceastld.github.io/wei-huo/

## 操作
- 键盘：WASD / 方向键移动，空格冲刺，G 观摩，R 重开本房
- 触屏：左下摇杆移动，右下「冲」冲刺；「观摩」跟玩当前房
- 鼠标：按住画布朝指针方向走

## 三十房
空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市 → 循径 → 双刃 → 回廊 → 灯巷 → 灰径 → 环行 → 密线 → 潮廊 → 种廊 → 油廊 → 急廊 → 拾廊 → 响廊 → 吸廊 → 冲廊 → 裂廊 → 贯廊 → 晕廊 → 冻廊 → 推廊 → 诱廊 → 壳廊 → 雷廊 → 绊廊。
吃到心核进下一房；绊廊心核通关。R 只重开当前房。HUD 显示房名和 1/30。
捡到焰种后，下一记干爆放大（半径 72），才能打开厚箱。
捡到急燃后，下一记干辙 0.55s 先爆；`TAIL_T` 仍 2.0。
捡到回爆后，下一记干爆 0.45s 后再炸同点；湿辙熄掉不消耗。开不了厚箱。
捡到吸爆后，下一记干爆把远处未爆干辙吸过来提前连环；湿辙熄掉不消耗。开不了厚箱。
捡到冲爆后，下一记冲把未爆干辙提前到 `CHAIN_T` 连环；湿辙跳过不引爆。空冲仍消耗。开不了厚箱。
捡到裂爆后，下一记干爆 0.28s 后沿面向垂直方向裂出两记卫星爆，间距 `SPLIT_D=80`；湿辙熄掉不消耗。开不了厚箱。
捡到贯爆后，下一记干爆沿面向射出 `PIERCE_L=200` 宽 `PIERCE_W=40` 的贯射线，顺路开普通箱；湿辙熄掉不消耗。开不了厚箱。
捡到环爆后，下一记干爆变成空心圈，内径 `RING_IN=40` 外径 `RING_OUT=80`；圈里安全，圈上仍伤、仍开普通箱；湿辙熄掉不消耗。开不了厚箱。
捡到霜爆后，下一记干爆冻住范围内敌人 `FROST_T=1.8` 秒；冻住时不移动、不碰伤；湿辙熄掉不消耗。开不了厚箱。
捡到推爆后，下一记干爆把范围内敌人径向推开 `SHOVE_V=280` / `SHOVE_T=0.40` 秒；飞的时候不碰伤；湿辙熄掉不消耗。开不了厚箱。
捡到诱爆后，下一记干爆在爆点留下灯诱 `BAIT_T=2.0` 秒，`BAIT_SEE=240` 内烬卫改走去灯；到点或到时爆；湿辙熄掉不消耗。开不了厚箱。
捡到雷爆后，下一记干爆对爆点 `BOLT_R=170` 外、半径内未砸中的敌人最多劈 `BOLT_N=3` 道，每道 1 伤；湿辙熄掉不消耗。开不了厚箱。壳卫仍按烫/干规则。
捡到绊爆后，下一记干爆在爆点埋一条绊线，`TRIP_R=16`，寿命 `TRIP_LIFE=12`；敌或己踩上触发烫爆；湿辙熄掉不消耗；回爆/裂爆卫星/诱爆弹出/雷弧都不埋线。
油渍可走，落辙变烫爆；水洼仍熄辙。
潮涌水洼 2.8 秒干、1.2 秒湿；涨潮会把还在潮里的焰辙熄掉。

站立不铺焰辙。辙 2.0 秒后爆，爆完留下余烬热斑约 0.55 秒，再留焦痕约 1.2 秒（只标位置，不伤；减动效可跳过）。自己的爆会伤自己；站在余烬里也掉 1 心。冲刺约 0.18 秒内不吃自己的爆、不吃余烬、不吃敌人碰，仍留烫辙。连环 3 次及以上读「3连」「5连」；5 连及以上额外顿帧与镜头 punch。
心×3。爆、碰敌人、出界各掉 1 心。受伤后 0.35 秒无敌。水洼熄辙。箱挡路，爆开才让。
**循辙**顺着你的活焰辙冲过来；没辙时只慢走。两下任意爆放倒。水洼切断它们的公路。
**灯蛾**扑向最近一次爆，约 1.2 秒，不追人。两下任意爆放倒。用爆把它引开、引入水洼、引入还没爆的焰辙。
**拾烬**吃掉未爆干辙，不追人。两下任意爆放倒。长辙会被吃掉；靠箱短铺仍能开洞。
**壳卫**厚壳，干爆 0 伤只挡；烫爆 / 油渍 / 焰种每记 1 伤，`SHELL_HP=2`。冲的烫辙才能破壳。
