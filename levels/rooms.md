# 尾火 · 房间

六房。数据在 `rooms.json`。坐标像素，原点左上。画布参考 960×540；房间自带 `w` `h`，按比例信箱进画布，不要拉扁。

词表只准：焰辙、烬卫、箱、水洼、心核、回星、收尾、烫辙。不要写 传送 / 飞行 / 三叉戟 / 激怒 / 天使 / 恶魔。

## 字段

每房：

| 键 | 含义 |
|----|------|
| `id` | 英数 slug |
| `name` | 中文原名 |
| `w` `h` | 场地 |
| `spawn` | `{x,y}` 出生，中心点 |
| `puddles` | 水洼，轴对齐矩形，`x,y` 左上，`w,h` 边长 |
| `crates` | 箱，`x,y` 中心。有货才写 `drop`：`心核` 或 `回星` |
| `enemies` | 烬卫，`x,y` 中心，`note` 给关卡意图，运行时可忽略 |

没有墙数组。房界就是界，出界掉心。箱当实心，爆开才让路。水洼只熄落上去的辙点，不挡人、不挡爆半径。

每房恰好一颗心核，都在箱的 `drop` 里。顺序 空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市。

const data = await fetch("levels/rooms.json").then((r) => r.json());
