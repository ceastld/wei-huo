# 尾火 · 房间

四十六房。数据在 `rooms.json`。坐标像素，原点左上。画布参考 960×540；房间自带 `w` `h`，按比例信箱进画布，不要拉扁。

词表只准：焰辙、烬卫、循辙、灯蛾、拾烬、壳卫、爆卫、余烬、焦痕、箱、水洼、油渍、潮涌、心核、回星、焰种、急燃、回爆、吸爆、冲爆、裂爆、贯爆、环爆、霜爆、推爆、诱爆、雷爆、绊爆、迟爆、跳爆、卷爆、镜爆、旋爆、洼爆、临洼、扇爆、鼓爆、脉爆、雨爆、泉爆、波爆、星爆、叉爆、收尾、烫辙。不要写 传送 / 飞行 / 三叉戟 / 激怒 / 天使 / 恶魔。

## 字段

每房：

| 键 | 含义 |
|----|------|
| `id` | 英数 slug |
| `name` | 中文原名 |
| `w` `h` | 场地 |
| `spawn` | `{x,y}` 出生，中心点 |
| `puddles` | 水洼，轴对齐矩形，`x,y` 左上，`w,h` 边长。`"tide": true` 为潮涌洼 |
| `oils` | 油渍，轴对齐矩形，同水洼但不潮。落辙变烫爆 |
| `crates` | 箱，`x,y` 中心。有货才写 `drop`：`心核`、`回星` 或 `焰种`。`"thick": true` 为厚箱，只有焰种爆才开 |
| `items` | 地上物，`kind` + `x,y`。种廊地面焰种、急廊地面急燃、响廊地面回爆、吸廊地面吸爆、冲廊地面冲爆、裂廊地面裂爆、贯廊地面贯爆、晕廊地面环爆、冻廊地面霜爆、推廊地面推爆、诱廊地面诱爆、雷廊地面雷爆、绊廊地面绊爆、迟廊地面迟爆、跳廊地面跳爆、卷廊地面卷爆、镜廊地面镜爆、旋廊地面旋爆、洼廊地面洼爆、扇廊地面扇爆、鼓廊地面鼓爆、脉廊地面脉爆用这个 |
| `enemies` | 烬卫、循辙、灯蛾、拾烬、壳卫或爆卫，`x,y` 中心，`type` 写原名，`note` 给关卡意图 |

没有墙数组。房界就是界，出界掉心。箱当实心，爆开才让路。水洼只熄落上去的辙点，不挡人、不挡爆半径。

每房恰好一颗心核，都在箱的 `drop` 里。顺序 空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市 → 循径 → 双刃 → 回廊 → 灯巷 → 灰径 → 环行 → 密线 → 潮廊 → 种廊 → 油廊 → 急廊 → 拾廊 → 响廊 → 吸廊 → 冲廊 → 裂廊 → 贯廊 → 晕廊 → 冻廊 → 推廊 → 诱廊 → 壳廊 → 雷廊 → 绊廊 → 迟廊 → 跳廊 → 卷廊 → 镜廊 → 旋廊 → 爆廊 → 洼廊 → 扇廊 → 鼓廊 → 脉廊。
