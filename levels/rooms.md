# 尾火 · 六房

给原型用的关卡表。数据以 `rooms.json` 为准。物件只用原名：焰辙、烬卫、箱、水洼、心核、回星。

坐标原点左上，单位像素。人、箱、烬卫的 x,y 是中心；水洼的 x,y 是矩形左上，另给 w,h。出界掉 1 心。

手感（跟 GDD 对齐，给实现参考，不改 `js/game.js`）：

| 键 | 值 |
| --- | --- |
| 尾延迟 | 2.0s |
| 辙点间距 | ~18px |
| 站立 | 不铺辙 |
| 普通爆半径 | 40 |
| 冲刺烫辙半径 | 68 |
| 人半径 | 12 |
| 箱 | 40×40 |
| 烬卫 | 半径 14，慢追，3 下爆死 |
| 敌人踩未爆辙 | 不提前引爆 |

吃到 **心核** 过关。箱可掉心核或 **回星**（回 1 心）。

## 1. 空场  `kongchang`

- 尺寸：720×480
- 出生：(96, 240)
- 箱：(560, 240) → 心核
- 水洼：无
- 烬卫：无

```
P ...................... [箱·心核]
```

**十秒课：** 跑一圈。两秒后，你的路会炸开这只箱。

意图：空场里只有你和一只箱。对着箱站住打不开——站着不铺雷。必须绕箱走一圈，让焰辙落到箱上，再让开，免得被自己的爆拍到。

## 2. 追者  `zhuizhe`

- 尺寸：800×520
- 出生：(70, 260)
- 箱：(730, 260) → 心核
- 烬卫 3：(320, 140)、(430, 300)、(340, 420)
- 水洼：无

```
        烬
P          烬                 [箱·心核]
        烬
```

**十秒课：** 别回头。让烬卫走进你的过去。

意图：大空地风筝。先画出弧，等两秒，让他们自己走进焰辙。三人各要三下。不要对着他们冲，更不要折返踩辙。人叠在一起时才用一次冲刺烫辙。

## 3. 水巷  `shuixiang`

- 尺寸：720×400
- 出生：(56, 200)
- 箱：(640, 190) → 心核
- 水洼：
  - (170, 150, 72×100) 过河前的教具，踩上去辙熄
  - (280, 60, 160×280) 正中水巷，堵死直路
  - (520, 308, 80×56) 箱南收尾洼
- 烬卫：无
- 干边：顶 y=0–60，底 y=340–400

```
........干边........................
P   [小洼]  [  水  巷  ]      [箱]
........干边..............[收尾洼]..
```

**十秒课：** 水洼熄辙。穿水收尾，或绕干路把爆带过河。

意图：心核在对岸箱里。直穿水巷会收尾，过河安全但没爆，还得在干地重新绕箱。走顶/底干边能把活辙带过河，到了再绕。箱南小洼用来收掉余辙，避免和箱爆叠伤。

## 4. 箱巷  `xiangxiang`

- 尺寸：680×440
- 出生：(48, 220)
- 水洼：无
- 烬卫：无
- 箱：上下两排夹巷（y=80 与 y=380，x=140…560 每隔 60），三道闸
  - 闸一 x=200，y=140/200/260/320，全空，只为开路
  - 闸二 x=380，y=140/200/320 空，**(380, 260) → 回星**
  - 闸三 x=560，y=140/200/320 空，**(560, 260) → 心核**（最后一箱）

闸间缝约 20px，人过不去，必须炸开一条廊。

```
################
P  #闸#  #回星#  #心核#
################
```

**十秒课：** 用爆开廊。中间那只回星是诱饵，心核在巷尾。

意图：逼你用焰辙炸巷，而不是找缝钻。第二闸的回星是假结尾（补心，不过关）。真的心核在第三闸正中那只。缺口处不要站着等爆，巷里掉头会吃自己。

---

## 5. 夹道  `jiadao`

- 尺寸：760×120（房界就是墙）
- 出生：(40, 60)
- 箱：(720, 60) → 心核
- 烬卫 1：(580, 60) 挡在箱前
- 水洼：无

```
|P ---------------- 烬 [箱·心核]|
```

**十秒课：** 普通辙贴边还能让。冲刺烫辙灌满夹道，死的是你。

意图：真正的威胁是自己的爆。普通半径 40，贴一侧铺，另一侧还能过。冲刺半径 68，120 宽的夹道会被灌满。尽头烬卫诱人按空格；冲到死胡同后，烫辙从身后灌进来。走，别冲。把烬卫和箱交给身后的普通爆。

---

## 6. 夜市  `yeshi`

- 尺寸：800×560
- 出生：(80, 280) 西口
- 箱：
  - (130, 90)、(670, 90)、(400, 56)、(670, 480) 空摊
  - (130, 480) → 回星
  - **(400, 280) → 心核**（场心，五人围着）
- 水洼：
  - (36, 180, 64×220) 西收尾槽
  - (700, 150, 64×220) 东收尾槽
  - (360, 400, 80×52) 场心南，绕箱时别把关键辙铺上去
- 烬卫 5：(400, 150)、(530, 220)、(510, 390)、(290, 390)、(270, 220)

```
[摊]      [摊]      [摊]
    烬         烬
[水]     烬 [心核] 烬     [水]
    烬         烬
[回星]                [摊]
```

**十秒课：** 混战。水洼收尾，箱当掩，心核在五人围着的场心。

意图：把前五房拼在一起。场心箱要绕着炸，同时五人在巡。湿路能收尾保命，也会救到跟着走湿的烬卫。西南回星是补心，不是过关。西口先进场，先别冲进环心。

## 实现注意

- 只加 `levels/*`。`js/game.js` 由别的工人写，不要改。
- 读房顺序按数组：空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市。
- `hint` 可直接做中文 UI 一行提示。
- `drop` 为 `null` 的箱炸开只让路。
- 水洼是轴对齐矩形；辙中心落入矩形即熄，不爆。
