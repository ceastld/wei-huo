# 尾火 · 房间

十一房。数据在 `rooms.json`。坐标像素，原点左上。画布参考 960×540；房间自带 `w` `h`，按比例信箱进画布，不要拉扁。

词表只准：焰辙、烬卫、循辙、灯蛾、余烬、箱、水洼、心核、回星、收尾、烫辙。不要写 传送 / 飞行 / 三叉戟 / 激怒 / 天使 / 恶魔。

## 字段

每房：

| 键 | 含义 |
|----|------|
| `id` | 英数 slug |
| `name` | 中文原名 |
| `w` `h` | 场地 |
| `spawn` | `{x,y}` 出生，中心点 |
| `puddles` | 水洼，轴对齐矩形，`x,y` 左上，`w,h` 边长 |
| `crates` | 箱，`x,y` 中心。有货才写 `drop`：`心核` 或 `回星` |
| `enemies` | 烬卫、循辙或灯蛾，`x,y` 中心，`type` 写原名，`note` 给关卡意图 |

没有墙数组。房界就是界，出界掉心。箱当实心，爆开才让路。水洼只熄落上去的辙点，不挡人、不挡爆半径。

每房恰好一颗心核，都在箱的 `drop` 里。顺序 空场 → 追者 → 水巷 → 箱巷 → 夹道 → 夜市 → 循径 → 双刃 → 回廊 → 灯巷 → 灰径。

## 给原型的读法

```js
const data = await fetch("levels/rooms.json").then((r) => r.json());
// file:// 与 Pages 都可用 js/rooms.js 内联的 WEI_HUO_ROOMS
```

## 7. 循径  `xunjing`

- 尺寸：840×520
- 出生：(80, 260)
- 箱：(740, 260) → 心核
- 循辙 2：(340, 140)、(340, 380)
- 烬卫 1：(540, 260)

**十秒课：** 你的路是它们的路。少铺辙，或让爆先到。

意图：大空地教循辙。没焰辙时它们只慢蹭；一画出干路，它们就沿辙冲过来。短铺、让开，两下任意爆放倒。

## 8. 双刃  `shuangren`

- 尺寸：840×520
- 出生：(70, 260)
- 水洼切断中场干桥；东还有一小洼
- 循辙 2 在对岸，烬卫 2 在西岸
- 箱：东北回星，东岸心核

**十秒课：** 水洼切断公路。湿路收尾，干路是它们的跑道。

意图：走干桥等于给循辙铺公路。穿水熄辙，公路断，它们只能慢走。

## 9. 回廊  `huilang`

- 尺寸：960×540
- 出生：(72, 270)
- 箱围成可绕的 U 廊；南臂两洼切断湿路
- 烬卫 2 在北廊、东廊；循辙 1 在北廊
- 西南廊回星，东南廊心核进灯巷

**十秒课：** 干廊铺一条长焰辙，连环引爆清场。湿路收尾，不连环。

## 10. 灯巷  `dengxiang`

- 尺寸：960×480
- 出生：(80, 220)
- 南一条水洼；北干路留给余辙
- 灯蛾 4：近身、水边、北干路、守心核
- 东北回星，东岸心核进灰径

**十秒课：** 爆能引开灯蛾。引入水洼，或引入还没爆的焰辙。

---

## 11. 灰径  `huijing`

- 尺寸：960×200
- 出生：(64, 100)
- 中线一串箱把径分成南北两道；余烬半径铺满一道
- 烬卫 1 在北径，逼你换边让开余烬
- 东北回星，东岸心核通关

**十秒课：** 爆完还烫。换到另一道，别站在余烬里。
